# Breath Loom 视觉方向

## Frame

- 玩家：在信息流中先看到“像活物一样呼吸”的黑白线场，触摸后立即发现它会随手收缩。
- 核心交互：单指塑形、松手呼吸回弹。
- 情绪承诺：像把一团由数万根极细纤维编成的肺握在手里。
- 状态：加载、原始呼吸、幽灵演示、触摸张力、释放峰值、复原、错误。

## Direction

选择“暗室里的白色纤维肺”。只使用黑与半透明白，保留原作朦胧残影；高光来自 80 条线的密度叠加，不用彩色光晕或纹理贴图。画面应介于科学仪器与有机雕塑之间。

## Interface System

- 黑色全屏背景，UI 白色。
- 标题：11px / 700 / `0.18em`；编号：9px / 600 / 42% 白。
- 复位按钮：44×44 透明触控区，1.5px 线性 SVG。
- 幽灵手：Google Material Symbols Rounded `touch_app`，白色实心，真实改变 line field。
- 不出现底部卡片、模式切换、进度条或操作文案。

## Motion

- Idle：原版帧速时间与残影。
- Touch：100ms 内线场向触点方向扭曲，700ms 达最大张力。
- Release：0–300ms 收束，300–950ms 外扩，950–2600ms 三次缓出复原。
- Reset：500ms 衰减，不闪黑。

## Responsive

- 线场 y 范围始终为 `height/2.5`，保留原作随视口拉伸的合同。
- 320×568 安全边距 16px，标题不换行；桌面只增加留白与线长。

## 反模式

- 不给线着色，不加第二套粒子、烟雾或星空。
- 不画手机边框，不用 Emoji，不自绘陌生手势图。
- 不用文字教单指操作；幽灵手必须同步实际形变。
