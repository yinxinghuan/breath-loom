# Breath Loom 需求文档

## 1. Overview

Breath Loom 是一个黑白线场互动体验：原作 80×200 点的左右镜像呼吸线持续留下微弱残影，玩家单指拖动可收紧、撑开和扭转同一线场，松手触发一次完整的 2.6 秒呼吸回弹并回到原始循环。

## 2. Visual Design

- 基线严格保留黑底、白色低透明度细线、原版残影与垂直镜像构图，不增加粒子、彩色 bloom、3D 道具或设备外框。
- 产品 UI 只有左上标题、右上复位 SVG 和真实 Material `touch_app` 幽灵演示；单指操作不写说明文案。
- 主尺寸 390×844 与 320×568，桌面扩展到 1440×900；canvas 使用 1–2 倍 DPR。
- `?baseline=1` 仅运行原版 80 条线、每线 201 个顶点和原时间倍率。

## 3. Game Mechanics

- 原始每帧用 `background(0,25)` 淡化；时间为 `frameCount*0.008`。
- 每条线的相位是 `i/80*TWO_PI`，每点 y 从 `-height/2.5` 到 `height/2.5`。
- x 由 `sin(pointPhase*PI)` 包络乘以 `wave1(60) + wave2(40) + wave3(centerComplexity 100) + 60`；左右各画一次。
- 产品触摸只改变上述 60/40/100/60 四项的倍率与相位偏移，idle 值均为 1/0 时还原原式。
- 按住 700ms 达到最大张力；拖动的 x 控制相位扭转，y 控制收束/扩张。
- 松手后的 2.6 秒：300ms 收束到峰值、650ms 向外扩张、1.65 秒缓出回原始参数。

## 4. Controls

- Pointer / Touch：单指按住并拖动改变呼吸幅度与扭转；松手触发回弹。
- Mouse：左键执行同一逻辑。
- Keyboard：`R` 或复位按钮在 500ms 内把所有交互参数衰减回原值。
- 首次玩家 pointerdown 立即取消幽灵演示。

## 5. Win / Lose Conditions

无失败。玩家按住至少 180ms 或移动超过 18 CSS px，再松手，即完成一次呼吸闭环；峰值约保留 220ms，随后自动复原并无限重玩。

## 6. Sound Effects

- 触摸：92 Hz 正弦，100ms，最大增益 0.018。
- 按住：不持续播放，避免覆盖线场的安静气质。
- 松手：138 Hz 正弦从 0.028 衰减 700ms，并叠加 276 Hz、300ms 的轻泛音。
- 幽灵演示静音；音频失败不影响视觉。
